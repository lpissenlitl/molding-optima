## 三条最该记住的结论

### 结论 1：调机不是"按优先级排序"，是**跑循环**

书的 STOP 方法论是 **Systematically → Think → Observe → Proceed**，
而且明确强调 **必须作为一个循环（cycle）使用**：
改完之后**回到 Systematically 重新评估效果**，而不是"改完就往下走"。

> **对本项目的含义**：「阶段推进」如果被实现成一条**单向直线**
> （充填 → 补缩 → 外观，一路过到底），就与行业方法论相悖。
> 行业做法是：**每一轮 = 一次完整 STOP 循环**；
> 「补缩」不是终点，发现新缺陷就**开新一轮循环**，而不是在同一次会话里一路加参数。
>
> 这也解释了为什么旧版经验里有「一轮只调一个量」——
> 它不是保守，是**循环的节拍**：一轮一个改动 + 一轮一次评估。

### 结论 2：**硬修（hard fix）vs 绕过问题（processing around）**

这是全书最有价值的一个区分，也是本书对"调机顺序"最直接的约束：

- **hard fix**：在模具或制品设计层面做**永久性**改动。
  物理改造成本前置，但**工艺窗口（process window）会大得多**，长期成本低。
- **processing around**：用工艺手段**绕过**一个非工艺的根因。
  能暂时出好件，但**工艺窗口被压窄**，缺陷只是被掩盖。

书中的判别方式：遇到缺陷先问
**"这个根因在 4M 的哪一类？"**
- 属于 **Molding process** ⇒ 工艺手段是**对症**的，可以调；
- 属于 **Mold / Machine / Material** ⇒ 工艺手段只能**绕过**，
  最多算权宜之计，真正的解在模具/设备/材料侧。

书中对缩痕（Sink）的原话逻辑（转述）：
> 缩痕的自然起点是二段压力；但如果二段压力被调低是为了掩盖**模具分型面损伤**，
> 那么降低压力反而会**制造出缩痕** —— 正确做法是修模具，而不是绕着损伤调工艺。

书中对短射（Short Shot）的原话逻辑（转述）：
> 为限制飞边（flash）而调低充填速度或转位，结果**导致短射** ——
> "绕过一个问题常常制造出另一个缺陷"。

> **对本项目的含义**：这正是"短射不能靠加保压掩盖"的**专业表述**。
> 工艺参数调整（`MEL` / `VPTL` / `PP` / `PT` / `IV` …）只能解决 **Molding process** 类的根因。
> 若根因在模/机/料，算法给出的"最优调整"必然是**绕过方案**。
>
> ⇒ **策略层需要能表达"这件事该由工艺解，还是该提示改模具/设备/材料"。**
> 这是当前策略清单缺失的一个维度（见「对本项目的映射」第 3 条）。

### 结论 3：调整必须有**判据**，不能只有"加大/减小"

书中每一条工艺对策都附带**可验证的判据**（转述举例）：

| 对象 | 书中的判据（方向性参考，非本项目直接可用值） |
|---|---|
| 充填比例 | Decoupled 工艺下一段充填到 **95–98%**，其余 2–5% 靠二段压力补齐 |
| 充填量 | 用 **fill only weight（仅充填重量）** 作为基准，不是"感觉够了" |
| 余料 | 压力能从机台传到型腔，前提是螺杆尖前有 **cushion**；书中提到至少约 **0.25 in** |
| 峰值注射压力 | 设定值应比所需段一峰值压力**高约 20%**，为粘度波动留余量 |
| 二段时间 | 通常设为**刚好超过浇口封冻（gate seal）所需时间** |
| 熔体温度 | 与 setup sheet 一致，容差约 **±10 °F**（测量误差范围内） |
| 模温 | **控制器设定值 ≠ 实际模面温度**，须实测/热成像 |
| 充填速度 | 以**充填时间**是否匹配 setup sheet 为准（控制器上的速度百分比设定**可能不代表实际速度**） |

> **对本项目的含义**：本项目规则库当前多为**定性**（"加大 PP0""延长 PT0"），
> 少数有定量目标（如按充填量比例解算行程）。书里的做法提示：
> **"调什么量"之外，还要有"调到多少"的判据来源**，
> 否则「加大」到底加多少就落回经验值。

## STOP 循环详解

| 步骤 | 关键动作 | 常见错误 |
|---|---|---|
| **S**ystematically | 把问题拆进 **4M**：Molding process / Mold / Machine / Material，逐类列潜在根因 | 只盯着眼前那个缺陷 |
| **T**hink | 推演**预期结果**与**副作用**；先问"这是**新问题**还是**长期存在**？" | 跳过这一步直接动手 |
| **O**bserve | 走机台巡检（设定值 vs 实际值、干燥机、冷水机、热流道、模温…）；建立**基线数据** | 只看制品，不看数据 |
| **P**roceed | **一次只改一个量**，改动要**足够大**到可能产生影响，改完**等工艺稳定**再评估 | 一次改多个；改太小看不出效果 |

循环回到 **S**：评估这次改动是否真的产生了影响。
**没有影响 ⇒ 该参数不是根因**，可复位到原记录值。

### 4M 归因框架

书中的鱼骨图（fishbone）传统上有 5M（人/法/机/测/料），
但**注塑排障只用 4M**——"人"能作用于其余 4M，故不单列。

| 类别 | 本项目对应 | 算法能做什么 |
|---|---|---|
| **Molding process**（成型工艺） | `IV` / `IP` / `PP` / `PT` / `CT` / `MEL` / `VPTL` / `MBP` / `BT` … | ✅ 工艺参数调整 = **对症** |
| **Mold**（模具） | 排气、浇口、冷却水路、顶出、分型面… | ❌ 只能提示，不能"调参解决" |
| **Machine**（设备） | 止逆阀、射嘴、速度线性度、载荷敏感性、热流道歧管… | ❌ 同上 |
| **Material**（材料） | 干燥、粘度、批次、回料、添加剂… | ❌ 同上 |

> 书中反复强调：4M 方法的目的就是**避免 processing around**，
> 保持**尽可能宽的工艺窗口**、减少报废与 PPM。

## 调整纪律（Adjusted-Change Discipline）

这一节是本项目"一轮只调一个量"的**理论依据**，逐条列出：

1. **一次只改一个东西**（Change one thing at a time）
   改了多个 ⇒ **无法判断哪个是根因**。
2. **改动要足够大**，大到"有可能产生影响"。
   改动太小 ⇒ 测不出影响，会被误判为"这个参数不是根因"（假阴性）。
   若改动过大引发新问题，可以再调回来。
3. **改完等工艺稳定**再看效果（Patience）。
   没耐心 ⇒ 连着改 ⇒ 效果无法归因。
4. **没有影响就复位**：该参数从"潜在根因"清单里划掉，恢复到有记录的原始工艺。
5. **一个潜在根因一个一个排除**，先从最可能的开始。
6. **数据才是证据**（data driven）：改动后必须有数据反馈。
7. **警惕"上次这么干就好了"**（"this worked last time" syndrome）：
   先理解问题，再套用上次经验。
8. **警惕"万金油"思维**（"flavor of the month"）：
   一个模具上有效的解，不一定适合所有场景。
9. **警惕"创可贴 +  duct tape"**：能让产线出货 ≠ 解决了问题。

## 验收四问（Proceed 步骤的判定）

改动之后，书里要求逐条确认：

1. **工艺调整是否仍在允许的工艺窗口内**？
2. **制品外观是否可接受**？
3. **制品尺寸是否可接受**？
4. **是否满足全部测试要求**？以及其他各项要求？

并且：**改动有效后要"再往深挖一层"**：
- 为什么需要这个调整？
- 这个调整对型腔内塑料的物理状态产生了什么影响？
- 新状态长期稳定吗、能持续产出好件吗？
- 工艺窗口是否足够宽？是否还有别的事该做？
- **这个问题是否也影响公司在产的其它产品**？
- 公司体系里要不要改点什么，防止复发？

> **对本项目的含义**：这四问就是**"这一轮调机算不算成功"**的判据。
> 本项目当前第 4 层（`check_params`）只校验**参数物理合理性**，
> 尚未覆盖「外观 / 尺寸 / 工艺窗口」这三问 ⇒ **已知差距**。

## 换缺陷的禁忌

> 书中明确：任何调整都要评估**副作用**，**不要用一个缺陷换另一个缺陷**。
> 原文举例：减少报废却造成装配问题，长期成本可能更高。

这与本项目"一次只解决一个缺陷"（`defect_selection`）的目标一致，
但书里给出的是**更强的一条**：即使本轮只解决一个缺陷，也必须评估它
**是否引入了新缺陷**（尤其外观 ↔ 尺寸 ↔ 周期 ↔ 飞边之间的连锁）。

短射章里的具体连锁示例（转述）：
- 为限飞边而降低充填速度 / 转位 → **引发短射**
- 为治烧焦而降低充填速度 → **工艺窗口被压窄**（烧焦其实是**排气不良**的信号 ⇒ 应修模排气）
- 浇口附近缩痕 ⇒ 常是**浇口未封冻**；而二段时间设得过短 ⇒ **整个制品缩痕**

## 观察与数据（Observe）

书里给的现场排查清单（"4M Basic 8"）与数据工具，对本项目"上下文采集"有参考价值：

**巡检项**：辅助设定值 vs 实际值、热流道控制器、温控机、冷水机、干燥机、
辅助设备（气体辅助）、锁模与机械手动作、修边工序、操作者手法、物料标识是否正确、
是否有**清晰的标准件**、有无损坏或错位。

**数据工具**：
- **Pareto 图**：80% 报废来自 20% 根因 ⇒ **决定本轮该集中攻哪个缺陷**
- **Scrap tally sheet**：按小时/班次统计报废，识别与班次相关的规律
- **Change log（变更记录）**：记录每次改动 + 对缺陷的影响，跨班次沟通用
- **Is / Is Not 表**：把问题拆成"是 / 不是"两栏，快速缩小范围
- **5 Why**：持续追问直到真根因
- **DOE**：需要交互效应时（全因子：冷模/热模 × 低/高二段压力 = 4 次）

> **对本项目的含义**：
> - **Pareto ⇒ 缺陷优先级**：当前 `defect_selection` 是"选一个缺陷"，但选**哪个**
>   应由报废占比驱动，而不是随机/固定顺序。
> - **Change log ⇒ 调机历史**：本项目的"上一轮效果评价"（`tuning_result`）
>   就是 change log 的结构化版本。
> - **Is / Is Not ⇒ 归因**："这次是短射还是欠重？"正是 Is/Is Not 的典型问题。

## Decoupled® / Scientific Molding（第 3 章）—— 工艺基准

**解耦注塑**是把"充填"与"保压"**解耦**成两个独立控制点的工艺体系。
书中给出的基准流程（Decoupled II®，RJG 定义）共 7 步：

1. **一段速度控制充填到 95–98%**（称为 `fill only shot`）：
   充填要**尽可能快**，同时保证质量；且**机器不得处于压力受限状态**
   （塑料压力接近 2000 psi 就应视为受限，以留出粘度波动余量）。
2. 多腔模做**型腔平衡研究**。
3. 用机台上的**转位（transfer position）**从一段速度控制切到二段压力控制。
   📌 **本项目口径**：该功能位是 `vps_pos`(`VPTL`)，在**注射行程公式里是起点下界 / 缓冲量**
   （注射行程 = `ML_N − VPTL`）。充填量的**第一顺位是胶量端 `met_end_pos`**，
   **MEL 偏大后才轮到 `vps_pos`**（工艺初始化已按产品状态设过）⇒ 与书中做法**不冲突**。
4. 二段压力用于**补偿冷却过程中的收缩**。
5. 二段压力的维持**时间由浇口封冻（gate seal）研究确定**；每副模都要判断"是否带封冻运行"。
6. **冷却时间**按制品顶出温度优化到最小周期。
7. 螺杆应在**开模前约 2–3 秒**回到射胶量。

这套流程与"注射阶段把产品打到差不多 + 加保压让产品保满"是同一件事的专业表述，
它的价值在于把**塑料流量**与**型腔压力**变成**两个互相独立的控制点**。

书中列出的收益（转述要点）：

| 收益 | 机理 |
|---|---|
| 充填更快 ⇒ 周期更短 | — |
| 充填更快 ⇒ 粘度更低更一致 | 更易充填、型腔压降更小 |
| **充填与保压分离** | 流量与压力成为**两个独立控制点** |
| 95–98% 充填重量 | 防止**型腔压力突升**导致模具损伤与飞边 |
| 浇口封冻研究 | 二段时间不再浪费在保压流道上 |
| 型腔平衡研究 | 各腔塑料状态一致 |

它在书中的定位是**工艺开发阶段的基准工艺**，用于：
- 建立**可重复**的充填基准（`fill only weight` 要**每副模都记录**）；
- 让后续排障有"标准工艺"可比对（书中反复出现 `documented process` / `setup sheet`）。

> **对本项目的含义**：
> `fill only weight` ⇒ 本项目的 `fill_gap`（充填缺口 = 目标重 − 实测重）
> 与 `fill_ratio`（按充填量比例解算行程）**正是这个概念**。
> 这条路径在行业上是有依据的，不是拍脑袋。
> ⚠️ 注意书中的方向性提醒：若工艺建立在 98% 充填上，
> **再往上充填就大概率飞边** —— 充填比例是**上限**，不是"越多越好"。

## 两条设计原则：可移植性与简单性

### 原则 A：**记录"塑料数据"，而不是"机器设定值"**

> 书中明确（转述）：应侧重记录**塑料数据**，例如**充填时间**与**仅充填重量**，
> 而不是纠结速度设定点。**用塑料数据，才能在机台之间、工艺之间迁移。**

这条把"可移植性"落到了具体做法上：

| 记录对象 | 可移植性 |
|---|---|
| 速度设定百分比、压力设定值 | ❌ 换机台就变 |
| **充填时间、充填重量、制品重量、周期时间** | ✅ 跨机台可比 |

> **对本项目的含义**：这是「短射不靠加保压掩盖」之外的**第二条可移植性判据** ——
> **推荐值应当建立在"塑料数据"上，而不是"设定值"上**。
> 本项目当前的策略上下文里已有 `actual_weight` / `target_weight` / `fill_gap`
> （属塑料数据），这与行业做法一致。

### 原则 B：**工艺越简单越好**

> 书中原话逻辑（转述）：一段充填若不需要做速度曲线，
> **为什么要用六段曲线？** 每多一层工艺复杂度，就多一处出错机会。
> 验证"充填重量与充填是否匹配既定工艺"，比逐段验证复杂曲线简单得多。

> **对本项目的含义**：分段参数（`inj_spd_1..6`、`hold_pres_1..5`…）的存在
> 是为了表达**多段曲线**；但"多段"本身有成本。
> 当工艺只需要单段时，**不要为了"更精细"而增加段数**。

## 对本项目的映射（小结）

| 书中的原则 | 本项目现状 | 差距 / 落点 |
|---|---|---|
| 一次只改一个量 | 策略有 `max_items` | ✅ 已覆盖（旧版 S2 的依据在此） |
| 改后等稳定、无影响就复位 | 有"反馈证伪链" | ✅ 已覆盖 |
| 调整要有判据 | 部分有目标值（如按充填比例解算行程），多数是"加大/减小" | ⚠️ 判据来源缺失，见 `03` 差距清单 |
| 不要用一个缺陷换另一个 | `defect_selection` 一次只解决一个缺陷 | ✅ 方向一致；但缺"副作用评估"这一层 |
| 4M 归因 | 无 | ⚠️ **策略无法区分"对症调整"与"绕过问题"** |
| 硬修 vs 绕过 | 仅在 `reason` 自由文本里隐含 | ⚠️ 需要结构化表达 |
| 验收四问 | `check_params` 只校验参数物理合理性 | ⚠️ 缺"外观 / 尺寸 / 工艺窗口"三问 |
| Pareto 定优先级 | 无 | ⚠️ 缺陷选择优先级缺失 |
| 新问题 vs 长期问题 | 无 | ⚠️ 跨轮次分支缺失（与旧版 S4「沿用上一模」相关） |
| 调机是**循环**不是直线 | 讨论中（阶段划分议题） | 🔶 待拍板：阶段模型必须是循环语义，不能是一次性直线 |
