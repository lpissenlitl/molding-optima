# 注塑专业参考资料（references）

本目录存放**注塑工艺的专业参考资料**及其**拆解笔记**，供 `backend/process` 的调机优化算法在设计
「调什么量、调到什么口径、什么顺序调」时查阅。

> ⚠️ 本目录只放**参考资料与知识笔记**，不放业务代码、不放运行期配置。
> 知识笔记是**只读参考**，不是规则源；规则源在 `backend/process/algorithms/` 与规则库表中。

## 阅读路线

**第一次读（理解全书骨架，约 30 分钟）**
1. `01` 的「三条最该记住的结论」→ 建立整体认知
2. `01` 的「STOP 循环」与「硬修 vs 绕过问题」
3. `02` 的短射章 → 这是本项目最核心的缺陷

**做策略/流程设计时**
1. `01` 全篇（尤其是「调整纪律」与「验收四问」两节）
2. `03` 的映射表（确认术语对应的是哪个字段）

**加一条新规则时**
1. `04` 先查是否已有同类规则（避免重复）
2. `02` 找对应缺陷章 ⇒ 确认「工艺侧手段」是否已覆盖
3. `03` 确认字段名与缺陷码
4. 若书里给的是**定量判据**（如 95~98%、≥0.25 in、峰值压力 +20%），
   本项目目前多是定性规则 ⇒ 这是一条**已知差距**，见 `03` 末尾「差距清单」

> 编号说明：`03` 的 `G1`–`G9` 是**差距**编号；`04` 的 `U-` / `SS-` / `SK-` / `FL-` / `BN-` / `CY-`
> 是**规则**编号。两套编号不是一回事，引用时别混。

## 使用纪律

0. 🔻 **书是「参考信息源」，不是「判据」。**
   它提供行业做法与思维框架，用来**补充信息**；
   **落地前必须与本项目工艺语义核对，冲突时以本项目为准**。
   最常见的坑是**名同未必义同** —— 术语名对上了，作用与优先级可能不同
   （例：充填量在本项目有**两个旋钮**：第一顺位是胶量端 `met_end_pos`，
   `vps_pos`（缓冲量）是 **MEL 偏大后的第二顺位** —— 与书中做法相容，优先级不同）。
1. **笔记是转述，不是原文翻译。** 关键结论用中文讲清逻辑，专业术语保留英文原词
   （如 `fill only weight`、`processing around`），因为行业沟通用的是英文词。
2. **书里"工艺参数"的数值不能直接搬进规则。** 本项目的机台、模具、材料各不相同，
   书中的判据（如 95~98% 充填）是**该书作者在特定工艺体系（RJG Decoupled®）下的推荐值**，
   只能作为**方向性参考**，落地前必须用本项目自己的 `setup sheet` / 实测数据校准。
3. **书里的"对策"是有前提的。** 每条对策在原书中都附带适用条件与陷阱
   （例如"若有泄漏，不要一直加大射胶量"）。**只搬结论不搬前提 = 制造新的错误规则。**
4. **术语映射会变。** 本项目参数重命名后，`03` 的映射表需要同步更新。
